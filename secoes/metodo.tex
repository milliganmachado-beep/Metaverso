\chapter{Método}
\label{cha:metodo}

\section{Natureza do estudo}

O presente trabalho é uma análise bibliográfica comparativa baseada em revisões científicas publicadas. Essa escolha metodológica é deliberada. Uma revisão sistemática própria exige que a busca em cada base, os registros recuperados, as duplicatas, a triagem e as exclusões sejam efetivamente executados e registrados. Como essa cadeia completa de auditoria não foi produzida para este trabalho, não é correto apresentar números de uma revisão própria como se fossem dados coletados.

PRISMA 2020 é uma diretriz de relato para revisões sistemáticas e fornece checklist e fluxogramas para comunicar de maneira transparente o que foi feito e encontrado. A própria publicação esclarece que PRISMA 2020 não é, por si só, um método para conduzir a revisão. PRISMA-S complementa esse quadro ao detalhar o relato das buscas bibliográficas e sua reprodutibilidade. \cite{page2021,rethlefsen2021}

\section{Estratégia de análise}

A análise foi organizada em quatro etapas:

\begin{enumerate}
    \item identificação de revisões científicas diretamente relacionadas ao metaverso;
    \item verificação dos objetivos, métodos e resultados quantitativos declarados pelos próprios autores;
    \item comparação dos focos conceituais, tecnológicos, arquiteturais e aplicacionais;
    \item construção de uma definição operacional para o projeto.
\end{enumerate}

Os números apresentados no trabalho são sempre atribuídos às fontes que os produziram. Por exemplo, os 447 registros e 30 estudos finais pertencem à revisão de Tukur et al.; os 237 registros iniciais e 103 estudos incluídos pertencem à revisão de Boztas et al. Esses valores não são somados entre si, pois derivam de estratégias, períodos, bases e critérios diferentes. \cite{tukur2024,boztas2025}

\section{Protocolo para uma futura revisão sistemática própria}

Para uma revisão sistemática própria, recomenda-se registrar previamente:

\begin{itemize}
    \item bases de dados utilizadas;
    \item data e horário da busca;
    \item string completa de cada base;
    \item filtros e limites aplicados;
    \item número de registros retornados por cada fonte;
    \item exportação dos resultados para uma base de rastreamento;
    \item identificação e remoção de duplicatas;
    \item critérios de inclusão e exclusão;
    \item motivos das exclusões na etapa de texto completo;
    \item lista final dos estudos incluídos.
\end{itemize}

Uma string conceitual que pode servir como ponto de partida é:

\begin{verbatim}
("metaverse" OR "metaverses")
AND
(definition OR conceptualization OR characteristics OR architecture)
AND
(technology OR technologies OR application OR applications
OR interoperability OR persistence)
\end{verbatim}

Essa string é apresentada como protocolo futuro, e não como uma busca já executada nas bases. A versão definitiva deverá ser adaptada à sintaxe de cada base e preservada exatamente como executada, conforme a orientação de reprodutibilidade do PRISMA-S. \cite{rethlefsen2021}

\section{Critérios propostos para a futura seleção}

Para a futura revisão sistemática própria, propõem-se os seguintes critérios:

\textbf{Inclusão:}
\begin{itemize}
    \item estudos científicos diretamente relacionados ao metaverso;
    \item estudos que abordem definição, características, arquitetura, tecnologias, aplicações ou interoperabilidade;
    \item texto completo disponível para avaliação;
    \item estudos publicados dentro do período que vier a ser definido no protocolo final.
\end{itemize}

\textbf{Exclusão:}
\begin{itemize}
    \item notícias, páginas comerciais e textos opinativos;
    \item trabalhos que apenas mencionem o metaverso sem analisá-lo;
    \item duplicatas;
    \item documentos sem texto completo quando este for necessário para avaliar a elegibilidade;
    \item estudos sem contribuição para as questões de pesquisa.
\end{itemize}

Esses critérios são apresentados como protocolo, não como critérios já aplicados a um conjunto quantitativo próprio.
